# 第16课：字符串格式化

## 1. f-string

```python
name = "小明"
age = 18
print(f"我叫{name}，今年{age}岁")
```

输出：

```text
我叫小明，今年18岁
```

## 2. 保留两位小数

```python
price = 12.5
count = 3
print(f"总价：{price * count:.2f}元")
```

输出：

```text
总价：37.50元
```

`:.2f` 的含义：

- `:` 后面是格式要求
- `.2` 表示保留 2 位小数
- `f` 表示按小数形式显示

## 3. 常见错误

### 忘记文字标签

错误：

```python
print(f"{score:.2f}")
```

正确：

```python
print(f"成绩：{score:.2f}")
```

### 中文冒号和英文冒号混用

题目要求中文冒号时，要写成 `：`，不要写成 `:`。

### 忘记保留小数

```python
print(f"单价：{price}")      # 12.5
print(f"单价：{price:.2f}")   # 12.50
```

## 4. 小结

- `f-string` 里普通文字照写，变量放在 `{}` 里
- 需要保留小数时使用 `:.2f`
- 输出格式要连同文字、单位、标点一起检查
